# Privacy Policy **OpenEMR Bulk FHIR Test App** Last updated: September 2026 ## 1. Purpose This application is a development and testing application used to evaluate **Practice Fusion FHIR and Bulk FHIR APIs**. ## 2. Data Usage The application may access healthcare data from Practice Fusion only for authorized testing and interoperability development purposes. The application does not sell healthcare data or use it for advertising. ## 3. Data Storage Any data accessed through the Practice Fusion FHIR API will be handled only for the purposes of testing and development. Sensitive healthcare information should not be stored in this public GitHub Pages website. ## 4. Security Authentication credentials, private keys, access tokens, and other confidential information are kept private and are not published on this website or in the application's public source files. ## 5. Third-Party Services This application uses the **Practice Fusion FHIR API** to access authorized healthcare data. ## 6. Contact For questions regarding this application or its data usage, please contact the application developer. ## 7. Changes This privacy policy may be updated when the application or its data usage changes.
